## Infrastructure

ExpertMD runs on Amazon Web Services (AWS):

| Layer | Technology | Protection |
|-------|-----------|------------|
| **Compute** | AWS ECS | Containerized deployment with isolated execution environments |
| **Database** | AWS RDS PostgreSQL | Encryption at rest, automated backups |
| **Storage** | AWS S3 | Server-side encryption for all documents |
| **Transit** | TLS 1.2+ | All traffic encrypted in transit |
| **Auth** | Clerk | Industry-standard authentication with MFA support |

## Compliance

- **HIPAA considerations** -- Sensitive medical data is encrypted end-to-end
- **Attorney-client privilege** -- Case data is encrypted and accessible only to authorized parties
- **Data minimization** -- We collect and store only the data necessary for platform operation

## Reporting Security Issues

If you discover a security vulnerability, please report it responsibly to **security@expertmd.io**. We appreciate and acknowledge responsible security researchers.
